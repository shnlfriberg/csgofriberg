监测边界：`transaction_ms` 是事务整体耗时，`recovery_command_ms` 是触发保底的整个引擎命令耗时；不能称作某一条 SQL 或纯保底算法的精确计时。运行指标是当前进程累计值，重启后归零；多实例需分别采集。Socket 运行指标统计逻辑 JSON 发包大小，不含传输封装或同身份多个标签页的复制倍数；下面负载测试另统计接收端实际 Socket 包。计数不保存身份或牌堆正文，窗口至多保留 1,000 房间。

## 玩法和界面

入口为娱乐模式 → 卡牌连接，地址 `http://localhost:5175/entertainment/card-link`。先选单人模式、每日挑战、多人模式或随机匹配，再设置并开始。单人手牌按钮为“单人模式-无限手牌 / 单人模式-限定手牌”；时间支持不限时（默认）及 120/180/300 秒，另有 30 分钟无有效操作过期规则。多人设置后创建 2—8 人好友房或按房间码加入；加入采用房主配置。随机匹配选择手牌后开始，保持普通难度、每轮 180 秒、3 轮和登录及邮箱验证要求。单人和好友房支持访客；每日固定普通难度、不限答题时间，北京时间次日 00:00 截止，可反复重做，每账号/日期/手牌模式只取最佳成绩上榜。
